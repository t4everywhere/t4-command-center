Optional: if Shortcuts is already available, create a shortcut with the Open App action, choose the app, and name it exactly T4 Notes, T4 Files, or T4 Photos. The corresponding tile then offers a button to run it. Only you create and approve these shortcuts; none are installed here.

Add to your iPad Home Screen

Use a hosted HTTPS copy in Safari. Tap Share → Add to Home Screen → Add. If your iPad offers “Open as Web App,” you may enable it. Menus vary with iPadOS. Opening a downloaded HTML file from Files can show a preview with limited behavior; use hosting for dependable access.

This is a single-file launcher, not an offline-installed app. The hosted page and external services need internet; offline reopening is not guaranteed.

Privacy & storage

No analytics, external fonts, libraries, automatic network requests, account integration or background jobs. The clock uses your iPad’s time and timezone. Your optional T4 link, review link, and favorite names, order and web addresses are saved in this browser’s local storage. Clearing website data removes it. Private browsing or storage restrictions may prevent saving.

If hosted publicly, the HTML source is public. Do not put passwords, confidential notes or private business data in the file. A saved link stays in this browser and is not sent by this dashboard.

Wallpaper & appearance

The charcoal glass and electric-blue/purple ribbons are drawn in CSS, so no wallpaper download is needed. This recreates the described style; the original wallpaper image was not supplied. Portrait, landscape and Split View adapt automatically. Reduced Motion is respected.
